화면 위 마커 표시

화면 속 특정 위치에 대한 답변이 필요할 때, Windows 앱이 답변 속 체크리스트와 연동된 작은 번호 마커를 게임 화면 위에 바로 띄워줍니다. 마커 기능은 이제 막 추가되어 계속 다듬어가는 중이니, 현재 지원되는 기능을 확인해 보세요.

원활히 작동하는 항목

  • 클래식 RPG, 탑다운 어드벤처 같은 2D 및 고정 카메라 시점 게임
  • 캐릭터가 이동해도 마커가 위치를 유지하며, 문을 통과하거나 씬이 전환되면 자연스럽게 사라집니다.
  • 체크리스트에서 항목을 완료하면 해당 마커가 사라집니다.

개선 중인 항목

  • 3D 게임에서는 멈춰 서 있을 때 마커가 표시되며, 카메라 시점을 돌리면 사라집니다.
  • 마커 위치가 살짝 어긋나거나, 대상 이름이 너무 포괄적으로 표시될 수 있습니다.
  • 웹 앱과 Steam Deck에서는 게임 화면 대신 답변 속 스크린샷 위에 위치가 표시됩니다.

마커가 제대로 작동하지 않는 게임을 발견하셨나요? 다음 채널로 알려주세요: Discord— 여러분의 제보가 큰 도움이 됩니다.

오버레이 하나로 완벽하게

몰입감을 깨지 않고 도움을 받고 싶은 진정한 게이머를 위해 만들었습니다.

자연스러운 데스크톱 오버레이

화면 가장자리에 깔끔하게 고정하거나 게임 옆에 띄워둘 수 있습니다. 로파이 픽셀 감성 또는 클래식 스타일 중 원하는 디자인을 골라보세요.

상황을 이해하는 AI

Gemini 기반으로 플레이 중인 게임을 인식하고 스크린샷을 분석합니다. 깊이 있는 답변이 필요할 때는 충분히 고민하여 완성도 높은 가이드를 제공합니다.

롤플레이 & 효율 극대화 모드

원하는 가이드 스타일을 선택해 보세요. 스포일러 없이 몰입감을 유지하는 롤플레이 힌트부터, 순수 수치 중심의 효율 극대화 모드까지 지원합니다.

컨트롤러 지원

패드를 내려놓을 필요 없이 오버레이를 열고, 빠른 질문을 선택하고, 가상 키보드로 바로 입력하세요.

플레이 메모장

자물쇠 비밀번호, 퍼즐 힌트, 퀘스트 목표를 적어두는 상시 메모장. 어떤 답변이든 클릭 한 번으로 메모에 저장할 수 있습니다.

Steam 연동 및 가이드

Steam에서 플레이 중인 게임을 자동 감지하고, 도전 과제를 추적하며, 게임 화면 바로 옆에 가이드를 띄워줍니다.

음성 안내

무료 내장 음성이나 프리미엄 Gemini 음성으로 답변을 소리 내어 들려주므로 게임 화면에 계속 집중할 수 있습니다.

영어, 스페인어 및 포르투갈어 지원

모든 플랫폼에서 앱과 답변이 설정한 언어로 제공됩니다.

    평소처럼 게임 플레이

  2. 2

    질문하기 또는 힌트 누르기

    질문을 입력하거나, 단축키를 누르거나, "길이 막혔어" 같은 빠른 프롬프트를 사용해 보세요. 화면을 공유해 AI가 보고 있는 화면을 직접 확인하게 할 수도 있습니다.

    화면에서 바로 답변 확인

자주 묻는 질문

Quest Compendium은 무료인가요?

신용카드 등록 없이 매일 Pro 2회, Fast 5회 질문으로 무료 체험해 보세요. Premium은 월 $4.99에 매일 Pro 8회, Fast 25회 질문이 제공되며, 남은 질문 횟수는 이월(각각 최대 100회)됩니다. 여기에 화면 마커 표시와 Gemini 음성 등 프리미엄 기능까지 모두 누릴 수 있습니다. 베타 기간에는 모든 플레이어에게 모든 기능이 제공됩니다. 자세히 보기: 요금제.

화면 마커 기능이 뭔가요?

화면에 보이는 아이템 위치나 공격해야 할 적 등을 질문하면, Windows 앱이 게임 속 해당 위치에 직접 번호가 매겨진 라벨을 띄워줍니다. 현재 초기 기능으로, 캐릭터가 움직여도 위치가 유지되고 장면이 바뀌면 사라지는 2D 및 고정 시점 게임에 가장 적합합니다. 3D 게임의 경우 가만히 서 있을 때 마커가 표시되며, 카메라 시점을 돌리면 사라집니다. 웹 앱과 Steam Deck에서는 답변 내 스크린샷 위에 해당 위치가 표시됩니다.

어떤 게임을 지원하나요?

화면에 띄울 수 있는 모든 게임을 지원합니다. Quest Compendium은 현재 플레이 중인 게임을 인식하고 스크린샷을 분석할 수 있습니다. 인기 게임일수록 가장 잘 파악하지만, 모든 AI와 마찬가지로 가끔 실수가 있을 수 있으니 중요한 정보는 다시 한번 확인해 주세요.

안티치트 프로그램에 제재를 받나요?

Quest Compendium은 게임 화면 위에 별도의 창으로 실행되며 표준 화면 캡처 방식을 사용합니다. 게임 파일을 변조하거나 게임 내에 코드를 주입하지 않습니다. 다만, 일부 경쟁형 온라인 게임은 오버레이나 화면 캡처를 제한할 수 있으며, 모든 안티치트 시스템의 정책을 보장할 수는 없습니다. 불안하시다면 해당 게임의 이용 규칙을 확인하시거나 싱글 플레이어 게임에서 사용해 주세요.

어떤 데이터를 어디로 전송하나요?

질문을 보내면 앱은 질문 내용과 게임 이름, 그리고 첨부된 스크린샷을 Quest Compendium 서버로 전송하며, 이 데이터는 답변 생성을 위해 Google의 Gemini AI로 전달됩니다. 로그인하시면 메모와 진행 상황이 클라우드에 동기화됩니다. 자세한 내용은 다음에서 확인하실 수 있습니다. 개인정보 처리방침.

Windows에서 "Windows의 PC 보호" 경고가 떠요. 안전한가요?

Quest Compendium은 1인 개발자가 제작한 최신 앱으로, 아직 직접 설치 파일에 코드 서명이 되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다. 계속 진행하시려면 추가 정보를 클릭한 뒤, 실행을 눌러주세요. 소스 코드는 GitHub). Microsoft Store 버전 에는 이 경고가 표시되지 않습니다.

Steam 계정이 꼭 필요한가요?

아니요, Steam 연동은 선택 사항입니다. 계정을 연동하면 Quest Compendium이 현재 플레이 중인 게임을 감지하고, 라이브러리를 동기화하며, 도전 과제를 자동으로 추적해 줍니다.

Steam Deck에는 어떻게 설치하나요?

Decky의 개발자 설정에서 링크를 통해 설치할 수 있는 Decky Loader 플러그인입니다. 위쪽의 Steam Deck 섹션 에 안내된 단계를 따라 진행해 주세요.

버그 제보나 기능 제안은 어디서 하나요?

앱 설정의 'Beta Feedback' 버튼을 이용하시거나, 공식 채널에 방문해 인사해 주세요. Discord, 또는 다음 주소로 이메일을 보내주셔도 됩니다. hello@questcompendium.com.
